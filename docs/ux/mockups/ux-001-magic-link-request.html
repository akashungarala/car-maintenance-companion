Decisions visible in this mockup

  • No "no account found". Registered and unregistered addresses produce the identical confirmation, so this form cannot be used to discover who has an account.
  • Loading keeps the form. Replacing it before the request succeeds means a failure returns the user to a blank field.
  • Success names the address. The most common failure here is not an error — it is a link sent to a typo the user cannot read.
  • 429 states the wait. "Too many attempts" without a number turns a temporary limit into an apparent dead end.
  • Label, not placeholder. A placeholder disappears the moment typing starts, taking the field's meaning with it.
